How it works+

The horizontal match

Source turn = mouse counts × sensitivity × m_yaw. Valve’s published Source SDK uses m_yaw = 0.022. Roblox’s published standard camera uses 0.5 degrees per horizontal mouse delta; Roblox documents that the client sensitivity and MouseDeltaSensitivity affect mouse delta.

/sens = Source sens × m_yaw × Source DPI / (Roblox sens × 0.5 × Roblox DPI)

The bhop multiplier follows your specified model: Roblox sensitivity × in-game /sens. At the same DPI with the default camera factor, this simplifies to Source sens × 0.044 / Roblox sens. Reverse mode solves the same equation for Source sensitivity.

Use the numeric Roblox value

Enter the actual camera sensitivity value, such as 0.2 or 1, rather than counting slider bars. The legacy Roblox slider uses a nonlinear mapping, so a bar number is not the sensitivity multiplier.
